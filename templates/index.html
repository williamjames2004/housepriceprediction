THE MACHINE LEARNING MODEL

How Random Forest predicts prices.

Your model uses a preprocessing pipeline followed by a Random Forest Regressor containing 200 decision trees.

01

Input Features

The application collects 12 features describing the house. Numerical values represent measurements and counts; categorical values describe facilities and furnishing.

  • 5 numerical features
  • 7 categorical features
  • 1 target: price
02

One-Hot Encoding

Categorical variables cannot be used directly by the tree model as text. OneHotEncoder converts categories into numeric indicator features.

  • Handles multiple categories
  • Ignores unknown categories safely
  • Uses the categories learned during training
03

Random Forest Regressor

Random Forest trains many decision trees using randomized samples and feature selection. Their predictions are averaged to produce a regression estimate.

  • 200 estimators (trees)
  • Random state set to 42
  • Captures non-linear feature relationships
04

Training and Evaluation

Your training script splits the data into training and testing subsets when at least five rows are present. It reports Mean Absolute Error (MAE), and R² when the test target contains more than one unique value.

  • Test size: 20%
  • Random state: 42
  • Final pipeline is retrained on all available rows
05

Prediction Pipeline

The trained pipeline is saved to house_price_model.pkl. Flask loads this file, prepares the submitted features in the expected order, and returns the predicted price.

  • Model persistence with Joblib
  • Consistent preprocessing at prediction time
  • Web interface powered by Flask

Understanding the evaluation metrics

MAE (Mean Absolute Error): The average absolute difference between actual and predicted prices. It uses the same price units as the target column.

R² Score: Indicates how well predictions explain variation in the target on the test set. It can be negative when the model performs worse than predicting the test-set mean.
